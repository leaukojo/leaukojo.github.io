# Leaukojo

A collection of automotive learning tools, simulations, and utilities for the RAMN ecosystem.

## Learning About Automotive Systems

### SloppyCAN

A browser-based CAN bus analysis tool focused on education and experimentation. No installation required.

➡️ [https://leaukojo.github.io/sloppycan/](https://leaukojo.github.io/sloppycan/)

### Carlito

A Godot-powered simulation featuring a small interactive world and simulated vehicles. Designed to integrate with RAMN and SloppyCAN for hands-on automotive learning.

➡️ [https://leaukojo.github.io/carlito_web/](https://leaukojo.github.io/carlito_web/)

## RAMN Tools

### RAMN Flasher

A web-based firmware flashing utility for the RAMN platform. Flash supported firmware directly from your browser without installing additional software.

➡️ [https://leaukojo.github.io/ramn-flasher/](https://leaukojo.github.io/ramn-flasher/)

Based on the RAMN project:
[https://github.com/ToyotaInfoTech/RAMN](https://github.com/ToyotaInfoTech/RAMN)

### RAMN CTF Replayer

A browser-based tool for replaying and exploring previous RAMN Capture The Flag (CTF) challenges.

➡️ [https://leaukojo.github.io/ramn-ctf-replayer/](https://leaukojo.github.io/ramn-ctf-replayer/)
